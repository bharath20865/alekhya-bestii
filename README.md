A compact GitHub Pages-ready single page made for Alekhya by Bharath.

## New: Alekhya on Highway 💗

A self-contained playable pink racing game made by Bharath for Alekhya. It lives separately in [`highway/index.html`](highway/index.html), so this original K-drama page remains unchanged.

- [Play source file](highway/index.html)
- Controls: arrow keys or WASD; on-screen touch controls work on mobile.
- Features: pink ALEKHYA car, BHARATH rival cars, fuel pickups, bonus hearts, score, best score, collision/game-over, and pause.
- No build step, framework, external asset, API key, or paid website builder required.

Open `highway/index.html` directly to play locally, or enable GitHub Pages in repository settings to publish the folder as a website.
