# ALEKHYA · K-Drama Bestie v3

A compact GitHub Pages-ready single page made for Alekhya by Bharath.

## What's different
- 6 **local** original K-drama-inspired images, so there are no broken remote-image boxes.
- Small page with no repeated sections.
- One beauty/gorgeous compliment only.
- YES-only final interaction and SEND PIC flow.
- No camera/gallery access.
- No external image scraping or hotlink dependency.

## Run
Open `index.html` directly, or upload the whole folder to GitHub Pages.

## Edit
