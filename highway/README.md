# Alekhya on Highway 💗

A self-contained browser racing game made by Bharath for Alekhya.

- Open `index.html` in any modern browser to play locally.
- Keyboard: Left/Right to steer, Up to accelerate, Down to brake. WASD also works.
- Mobile: use the on-screen driving controls.
- Avoid BHARATH cars, collect fuel cans, and hearts add bonus points.
- No framework, build tools, external assets, account, or API key is required.

The `index.html` page contains all HTML, CSS, Canvas 2D rendering, and JavaScript in one file.
